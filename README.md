# ponderosa-mockups

Public listing-photo assets for Ponderosa Patchworks (Etsy / Printify).

- `blanks/gildan-64000/<color>/` - blank shirt photos used to build listing mockups
- `info-cards/gildan-64000/` - size guide and fabric cards
- `listings/<listing>/` - finished 20-photo sets, one folder per listing
- `manifest.json` - index of every file

Print-ready design files are NOT stored here.
